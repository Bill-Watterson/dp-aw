Nesta atividade, desenvolvi uma página HTML contendo uma tabela com três colunas e cinco linhas, organizada para apresentar informações de forma clara e estruturada.  
Utilizei CSS externo para definir as cores, a fonte e o alinhamento, deixando o visual mais limpo e agradável.  
O objetivo principal foi praticar a criação de tabelas no HTML e a aplicação de estilos externos com CSS.
