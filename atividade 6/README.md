Nesta atividade, desenvolvi uma página HTML chamada “navegacao.html” utilizando âncoras e navegação interna.  
A estrutura contém três seções: Início, Sobre e Contato, cada uma identificada por um ID específico.  
Os links no menu superior permitem rolar a página até a seção correspondente.  
O objetivo principal foi praticar o uso de links internos em HTML.
