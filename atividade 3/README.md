Nesta atividade, desenvolvi uma página HTML contendo uma tabela de horários de aulas da semana, com cabeçalho, corpo e rodapé organizados de forma clara.  
Utilizei CSS externo para definir cores, bordas, espaçamento e destaque para o intervalo, tornando o visual mais harmonioso.  
O objetivo principal foi praticar o uso de tabelas no HTML e o aperfeiçoamento do estilo por meio do CSS externo.
