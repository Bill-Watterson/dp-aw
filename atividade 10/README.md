Nesta atividade, desenvolvi uma página de apresentação chamada “index.html” com o tema “Vôlei em Ação”.
A página apresenta informações sobre o projeto, suas modalidades e um formulário de contato.
Foram utilizadas tags semânticas e um CSS externo (“style.css”) para definir cores, fontes e organização visual.
O objetivo principal foi praticar a criação de uma página semântica e bem estruturada com HTML e CSS.
