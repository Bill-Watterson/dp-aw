Nesta atividade, desenvolvi uma página HTML com o tema “Coisas de Vôlei”, composta por cabeçalho, menu de navegação, conteúdo principal e rodapé.
Utilizei CSS externo para definir cores, layout e espaçamento, deixando o visual mais organizado e agradável.
O objetivo principal foi praticar a criação da estrutura básica de um site e a aplicação de estilos externos.
