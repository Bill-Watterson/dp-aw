Nesta atividade, desenvolvi uma página HTML chamada “Página Institucional”, representando o site de uma escola fictícia.  
A estrutura utiliza as tags <header>, <nav>, <main>, <section> e <footer> para organizar o conteúdo.  
Criei também um arquivo CSS externo para aplicar cores, fontes e margens, deixando o visual mais agradável e harmônico.  
O objetivo principal foi praticar a criação da estrutura completa de um site e o uso de estilos externos com CSS.
