Nesta atividade, desenvolvi uma página HTML com um formulário de contato simples, contendo campos para nome, e-mail e mensagem, além de um botão de envio.  
Utilizei CSS externo para definir cores, espaçamento e formatação dos elementos, tornando o layout mais limpo e organizado.  
O objetivo principal foi praticar a criação de formulários no HTML e o uso básico de estilos com CSS externo.
