Nesta atividade, desenvolvi uma página HTML chamada “form-estilizado.html” e um arquivo CSS externo “form.css”.  
Foram aplicados estilos aos campos e botões do formulário, incluindo efeitos de foco (:focus) e de interação (:hover).  
O objetivo principal foi aprimorar a aparência e a usabilidade de formulários HTML por meio do CSS.
